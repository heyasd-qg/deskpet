# Live2D角色制作器 v0.1

这是一个离线运行的单图角色动画试验程序，后续反馈继续在本项目修改。

## 启动

双击 `启动Live2D角色制作器.cmd`，或用 Chrome / Edge 打开 `index.html`。无需安装、联网、API 密钥或启动服务器。浏览器需支持 WebGL。

## 功能

- 内置蓝底测试角色，支持选择 JPG、PNG、WebP 图片。
- 自然待机、眨眼、说话、呼吸、轻摆和静态预览。
- 暂停、重播、原姿对比，调节幅度和播放速度。
- 可选蓝色背景去除，三种预览底色。
- 拖动眼睛、嘴巴标记校准位置，调整区域宽度。
- 保存和打开 JSON 试验工程，包含原始图片和参数。

新图片需手动校准五官。校准会暂时冻结动作，关闭校准开关后继续播放。空格可播放或暂停。

## 当前边界

本版使用单张纹理、WebGL 网格变形和程序绘制的临时闭眼、口腔素材。没有自动识别五官，没有 AI 拆层、补画、语音同步，也不生成或导出 `.moc3` / `.cmo3` 模型。转头只表现为轻微二维歪头。蓝底去除采用颜色规则，复杂蓝色服装可能受影响，可关闭。

## 开发入口

- `app.js`：交互、校准、工程读写。
- `renderer.js`：去底、五官动画、WebGL 网格渲染。
- `motions.js`：动作配置和时间曲线。
- `style.css` / `index.html`：界面。
- `builtin.js`：内嵌测试图片，离线可用。

请保留整个目录。工程 JSON 保存在浏览器的下载位置，通过“打开试验工程”恢复。程序不会自动保存未导出的修改。

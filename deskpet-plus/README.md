# Deskpet Plus

当前版本：0.9.2-beta.1。Electron 桌宠框架，角色资料可选；没有角色时仍可启动并打开工坊。支持导入 Live2D 模型、动作和表情控制、参数调节、双人显示及外置角色资料包。校验采用异步分块读取，显示进度并支持取消。

完整的功能介绍、模型导入步骤、原角色资料恢复和常见问题，见[仓库首页使用说明](../README.md)。

**第一次使用请先看：[用户使用指南](../docs/使用指南.md)。**

原内置角色为 **MyGO!!!!! 与 Ave Mujica 的 10 位角色**，当前完整资料包登记 51 套服装。安装完整资料后，可使用原角色的点击台词与日语配音、预设双人对白、随机互动、音乐演奏，以及已适配角色的《春日影》特殊反应。功能与触发条件见首页“安装完整资料包后的功能”。

## 本机直接运行

双击本目录的 `启动程序.cmd`。本机附带的 `desktop-pet` 运行目录与启动脚本默认不上传到源码仓库。

恢复原角色时，将上一级“内置角色资料”中的整个 `character-resources` 文件夹复制到本目录的 `desktop-pet` 内，与 `SakikoDesktopPet.exe` 同级。再启动程序，或点击工坊中的“刷新角色库”，随后可以校验资料包并在角色设置中选择原角色。

资料包保留原角色标识、服装与动作绑定、普通语音、双人对白及互动表情。个人设置、后来导入的自定义角色保存在程序自己的 `data` 中，不在公开源码或原角色资料包里。

## 从源码运行

准备 Node.js 22.12.0 或更高版本并确保 npm 可用，在本目录的 `app` 文件夹中执行：

```powershell
npm ci
npm start
```

首次安装需要下载 Electron 和构建依赖。源码版的设置与自定义角色保存在 `app/data`；源码模式恢复整套原角色时，把 `character-resources` 放到 `app` 内，与 `main.js` 同级。

`app` 源码目录不嵌入角色模型、语音、对白资料或内置测试图片；原资料由独立发布附件提供，本机仍单独保存在上一级“内置角色资料”目录。单图试验台可自行选择图片。PSD2Live 制作入口通过用户选择的外部程序接入，没有将其程序或源码打包进本仓库。

## 从源码打包

在 `app` 中执行：

```powershell
npm run package
```

使用 Electron Packager 独立构建，输出到 `deskpet-plus/dist`，不依赖原 Beta 目录。打包会排除角色资料、个人数据和开发依赖，生成的应用仍可通过同级 `character-resources` 恢复角色。目标平台默认是执行构建时的平台。

源码打包入口已经做过语法与排除规则检查；本次未重新联网下载依赖并完成一次完整的独立打包。框架、角色资料恢复及异步校验的自动检查已在原 Beta 中完成，实际桌面窗口与扬声器播放仍需实机验收。

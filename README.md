# Deskpet Plus

一个面向 Windows 的 Live2D 桌宠框架。导入自己的角色模型，在桌面上预览动作、切换表情和配饰，也可以同时显示两位角色。

**当前版本：0.9.2-beta.1。程序与角色资料分离，没有角色资源时也可以启动。** 程序源码位于 `deskpet-plus/app`。原内置角色资料和 Windows 便携程序作为独立发布附件分发，不放入 Git 历史；附件是否可下载，以实际发布版本为准。你也可以导入自己的 Live2D 模型。

> **第一次使用，请先阅读：[用户使用指南](docs/使用指南.md)。**
>
> 普通用户：使用 Windows 便携包 → 解压 → 启动程序 → 放入完整角色资料 → 刷新并选择角色。便携包是否可下载，以实际发布版本为准。
>
> 开发者：下载源码后进入 `deskpet-plus/app`，执行 `npm ci`、`npm start`。绿色 Code 按钮下载的源码 ZIP 不包含 Windows 运行程序。

## 功能

| 功能 | 说明 |
|---|---|
| 导入 Live2D | 从模型文件夹或 ZIP 导入，检查模型入口、MOC3、贴图及引用文件 |
| 角色工坊 | 预览模型，调整名字、待机动作、点击动作、默认表情和桌面位置 |
| 表情与配饰 | 根据模型实际资源生成按钮，支持组合；已识别的同类眼神、体型和眼镜可互斥切换 |
| 动作与手势 | 识别独立动作、表情及部分 VTube Studio 配置，支持单次、循环和保持姿势 |
| 参数与物理 | 调整实际模型参数、物理强度、自动呼吸和鼠标跟随 |
| 单人／双人 | 自定义角色可放到单人桌面或双人模式的左侧、右侧 |
| 外置角色资料 | 安装完整资料包后加载原角色配置、台词、语音和双人互动资料 |
| 资料完整性检查 | 异步分块校验 SHA-256，显示进度并支持取消 |
| 单图试验 | 选择图片、校准五官，预览眨眼、说话、呼吸和轻摆效果 |
| PSD2Live 接入 | 可选择外部 PSD2Live 程序，生成后再导入预览；工具本体不随仓库提供 |

功能取决于模型提供的素材。导入一个新角色不会自动生成原声、人物性格或专属对白；原角色的演奏与双人对白需要对应的完整资料包。

## 安装完整资料包后的功能

### 角色、服装与日常动作

- 在“角色设置”中切换 MyGO!!!!! 或 Ave Mujica 的角色和服装。
- 各角色拥有资料中配置好的待机、点击和情绪动作，可以在设置窗口预览。
- 单人模式下可以开启鼠标目光跟随；闲置时会播放预设的随机动作。
- 支持调整桌宠大小、整体拖动位置和保持闭眼。
- 支持面具的服装可设置日常佩戴状态，预览戴上／摘下面具动作；演奏时的面具状态可以独立设置。

并非每套服装都提供面具或相同的动作，界面会根据当前服装的配置开放对应功能。

### 点击台词与日语配音

点击日常状态下的角色，会从该角色的台词中随机选择内容，显示气泡，并在开启配音时播放对应原声。当前资料包包含 387 条带配音的普通台词。

- 字幕可选择中文或日文，现有配音为日语。
- 气泡显示、语音播放和桌宠音量可分别调整。
- 原角色的点击动作会与台词一起触发；演奏、预览或互动期间会协调或暂缓普通点击动作。

### 双人同屏与角色之间的互动

在“双人设置”中开启双人模式，分别选择左侧与右侧人物。两侧可以独立选择角色、服装与面具状态，拖动时作为一个桌宠组一起移动。

**配对对白：** 当前资料包含 20 组角色配对、80 段预设双人对话。同乐队中具有配对资料的两位不同角色，在组合切换并加载完成后，会触发一轮对应对白。双方会按台词顺序轮流说话，配合各自的表情与动作；倾听的一方也会做出相应反应。有对应配音且语音已开启时，会播放原声。

**日常随机互动：** 用户约 15 秒没有操作后，程序会按条件继续发起随机互动，从支持的配对对白或日常对白中选择内容。一轮结束后通常等待约 30～60 秒再发起下一轮，避免持续重复播放。

**锁定后持续互动：** 开启桌宠的锁定显示后，双人模式可以在用户继续操作其他窗口时，仍按间隔发起随机互动。锁定同时固定桌宠位置并保持置顶。

**跨乐队与其他组合：** MyGO!!!!! 与 Ave Mujica 的跨团组合会先进行通用文字问候；当前这段通用问候没有配音，之后按现有逻辑播放随机动作。左右选择同一个角色可以同屏显示，但不触发面向两位不同角色编写的配对对白。

切换角色、服装或进入动作预览时，互动会按当前状态重新协调。双人模式会停用鼠标目光跟随，关闭双人模式后恢复原来的单人设置。当前互动使用预设资料，不会自动生成新的剧情或 AI 对话。

### 音乐播放与乐队演奏

当 Windows 媒体会话报告音乐或视频正在播放时，原角色可以切换到对应的演奏模型，按角色定位播放主唱、吉他、贝斯、鼓或键盘表演动作。播放停止后返回日常状态。

- 演奏使用预设的演出服与动作序列。
- Ave Mujica 支持对应演奏模型的面具设置。
- 可在“角色设置”中手动预览演奏。
- 演奏时仍可按当前状态协调双人对白与互动表情。

该功能依赖播放器提供系统媒体会话信息，部分网页或软件可能无法被识别。演奏根据播放状态触发，使用的是预设动画，不进行音频节拍分析。

### 《春日影》特殊反应

单人模式下，当系统媒体标题被识别为“春日影”或“Haruhikage”时，已适配的角色会进入特殊反应，周期性播放对应的哭泣表情和动作。

当前适配角色为：**高松灯、长崎爽世、椎名立希、若叶睦、丰川祥子**。实际表情表现还受当前服装和面具状态影响。

双人模式下，《春日影》按普通音乐演奏处理；特殊反应依赖媒体标题识别，不是通过麦克风或音频内容识别歌曲。

### 日常提醒与桌面显示

- 支持早安、午安、晚安文字问候，每个时段最多提醒一次。
- 可开启整点报时，或从托盘菜单手动查看当前时间。
- 可设置免打扰时段；主动问候会避开音乐播放或互动等忙碌状态。
- 未锁定时，检测到与桌宠区域重叠的全屏窗口会暂时隐藏桌宠；锁定时保持显示。
- 拖动或调整屏幕后，会尽量将桌宠保持在可见区域内。

这些预设行为针对原角色资料进行适配。第三方导入角色可使用自身已有的动作、表情和控制功能，不会自动获得原角色的配音、配对对白或《春日影》特殊反应。

## 快速开始

### 环境

- Windows。桌面状态与媒体检测使用 Windows 接口，其他系统尚未适配验收。
- Node.js **22.12.0 或更高版本**，并可使用 npm。这是当前构建依赖声明的最低 Node.js 版本。
- 首次安装依赖时需要联网下载 Electron 等组件。

### 从源码启动

下载或克隆本仓库，在仓库根目录打开 PowerShell，执行：

```powershell
cd .\deskpet-plus\app
npm ci
npm start
```

首次启动没有角色是正常情况，程序会打开角色工坊，提示导入模型。源码仓库不包含可以直接双击的 EXE。

## 导入自己的 Live2D 角色

### 准备文件

| 文件 | 用途 |
|---|---|
| `*.model3.json` | 模型入口，记录模型本体、贴图及其他资源路径 |
| `*.moc3` | Live2D 运行模型本体 |
| PNG／WebP 等贴图 | 按入口文件中的原路径放置 |
| 动作、表情、物理等文件 | 模型引用这些文件时需要一并提供；它们决定可用功能 |

保留模型原来的目录结构。若入口引用 `../../assets`，请选择包含共用 `assets` 的上级目录，或将整套目录打成 ZIP。

只有 `.cmo3` 编辑工程、PSD 或一张图片，不能直接当作完整运行模型导入。缺少入口且只有一个 MOC3 和一组图片时，程序可以尝试生成基础入口，但贴图顺序需要预览核对，缺失的动作与表情不能凭空恢复。

### 操作步骤

1. 在角色工坊点击“导入模型文件夹”或“导入 ZIP”。
2. 一个包里有多个模型入口时，选择要使用的入口并填写角色名字。
3. 加入角色库后，先检查模型预览、贴图和动作是否正常。
4. 调整位置与缩放，设置待机、点击动作或默认表情。
5. 预览成功后，选择“单人桌宠”“双人左侧”或“双人右侧”，点击“放到桌面”。

“表情 / 配饰 / 手势”可进入模型功能区。工坊中的控制会同步到桌面上使用同一角色的实例。快捷键目前作用于工坊窗口，需要主动勾选启用；输入文字时不会触发。

导入资源总量上限为 768 MB，单个资源文件上限为 128 MB；暂不支持 ZIP64。较新或特殊模型是否兼容，应以实际预览为准。

## 安装完整的原角色资料包

整套原角色资料采用外置文件夹加载。拥有对应资料包时，**复制整个 `character-resources` 文件夹**，不要修改内部路径、文件名和角色标识。

| 运行方式 | 放置位置 |
|---|---|
| 从源码启动 | `deskpet-plus/app/character-resources`，与 `main.js` 同级 |
| 自行打包的应用 | 与 `DeskpetPlus.exe` 同级 |
| 本机附带的旧名便携副本 | `desktop-pet/character-resources`，与 `SakikoDesktopPet.exe` 同级 |

资料包通常包含以下内容：

| 路径 | 内容 |
|---|---|
| `characters.json`、`characters/` | 原角色标识、服装、模型、贴图、动作、表情、台词和普通语音 |
| `interaction-data.json` | 双人对白、日常对白和互动表情参数 |
| `interaction-voice/` | 双人互动语音 |
| `pack-manifest.json` | 文件长度和 SHA-256 校验清单 |
| 其他原目录 | 旧版模型资源、单图试验素材等，整包保留即可 |

放好后启动程序；如果程序已经打开，点击“刷新角色库”。再点击“校验角色资料包”，确认文件完整后，从“角色设置”选择原角色和服装。

如果资料已识别但桌宠尚未显示，可从系统托盘菜单选择“显示桌宠”。

双人互动需要在“双人设置”中启用双人模式，并选择资料包支持的角色组合。配音与音量在“系统设置”中调整，原有语音开关、免打扰和演奏规则继续生效。自定义导入角色不会自动加入专为原角色编写的双人对白。

资料包不是程序启动的必要条件。完整资料以独立 ZIP 发布，安装时解压并复制其中的 `character-resources` 文件夹；本机保存的“内置角色资料”目录不进入 Git 历史。资料包不包含用户个人设置，也不代表额外授予角色模型或语音的再分发许可。

## 设置与数据保存

| 内容 | 位置 |
|---|---|
| 源码模式设置、自定义角色和制作记录 | `deskpet-plus/app/data/` |
| 便携应用的设置、自定义角色和制作记录 | EXE 同级的 `data/` |
| 导入角色登记与副本 | `data/user-characters/` |
| 已移出的导入角色副本 | `data/user-characters/_trash/` |

从角色库移出角色不会删除用户最初提供的 ZIP 或文件夹。升级或更换运行目录时，保留原 `data` 目录可以保留设置和导入角色。源码模式与便携应用使用各自的数据目录。

资料校验只读取文件进行比对，不会改写角色素材。校验仍需要一定时间，取决于资料体积和磁盘速度；可以查看进度，也可以取消。

## 从源码打包

在 `deskpet-plus/app` 中完成依赖安装后执行：

```powershell
npm run package
```

构建输出到 `deskpet-plus/dist`，平台默认采用当前执行环境的平台，生成的可执行文件名为 `DeskpetPlus`。打包规则排除角色资料、个人数据和开发依赖；构建后的应用仍可安装外置资料包。

Git 历史中不包含便携运行文件。维护者本机用于测试的 `desktop-pet` 和启动脚本被 `.gitignore` 排除，便携包可以在发布版本中单独分发；是否已有下载，以实际发布版本为准。

## 当前限制与验证范围

- 摄像头面捕、麦克风口型和 VBridger 尚未接入；识别 VTube Studio 配置不等于完整复刻其运行功能。
- 双人模式停用鼠标目光跟随，返回单人后恢复原设置。
- 单图试验生成的是动画预览，尚不能将任意正面图片自动导出成标准 Live2D 模型。
- PSD2Live 是外部可选工具，需单独准备可运行的程序；真实 PSD 生成流程尚未完成验收。
- 模型导入、资源控制、原角色资料恢复和异步校验已在开发版本完成自动检查。实际桌面窗口、扬声器播放及公开源码导出的完整独立打包流程仍需实机验收。

## 常见问题

**启动后没有角色？**

源码默认不附带角色。先导入自己的 Live2D 模型，或按上面的路径安装完整资料包。

**模型能显示，但是没有表情、动作或声音？**

先确认原模型是否包含相应资源，并在工坊中重新扫描。角色导入不会自动生成缺失素材；语音和专属对白还需要对应的资料与绑定。

**放回模型后，为什么双人互动没有恢复？**

完整恢复还需要角色登记、对白配置、互动表情参数和互动语音。请安装整套 `character-resources`，再刷新并校验，而不是只复制其中的模型目录。

**依赖安装失败？**

检查 `node --version` 是否满足 22.12.0 及以上，并确认当前网络可以下载 npm 与 Electron 依赖。反馈问题时可附上错误输出，避免包含账号凭据或个人配置。

# 用户使用指南

## 先分清下载内容

| 内容 | 能否直接双击运行 | 用途 |
|---|---|---|
| Windows 便携程序 ZIP | 解压后可以，不需要安装 Node.js | 普通用户使用桌宠 |
| 绿色 Code 按钮下载的源码 ZIP | 不能直接作为便携程序运行 | 开发者按源码步骤安装依赖 |
| 原内置角色资料包 | 不是运行程序 | 恢复 MyGO!!!!! 与 Ave Mujica 原角色资料 |

便携包是否已经发布，以仓库的实际发布版本为准。没有便携包时，可以使用下文的源码运行方式。

## 一、使用 Windows 便携程序

1. 将程序 ZIP 完整解压到一个可以写入文件的目录。
2. 打开解压后的 `DeskpetPlus` 文件夹，双击 **`启动程序.cmd`**。
3. 首次没有角色时，程序打开角色工坊并显示导入提示，这是正常状态。
4. 按下一节安装原内置资料，或在工坊导入自己的 Live2D 模型。

请在完整解压后启动，保留 `desktop-pet` 内全部文件。程序需要在运行目录写入设置和角色数据。

## 二、安装原内置角色资料

### 第一步：找到完整资料文件夹

使用资源 ZIP 时先完整解压；使用本机保留的资料时，打开“内置角色资料”目录。找到其中名为 **`character-resources`** 的文件夹。原资料通过独立发布附件提供，绿色 Code 按钮下载的源码 ZIP 不包含这套资料。

其内部应能看到 `characters.json`、`characters`、`interaction-data.json`、`interaction-voice` 和 `pack-manifest.json` 等内容。

### 第二步：整包复制到正确位置

便携程序放置位置：

`DeskpetPlus/desktop-pet/character-resources`

也就是与 **`SakikoDesktopPet.exe` 同级**。保留 `character-resources` 这一层名称，内部文件不要拆开或改名，也不要放进 `resources`、`data` 或另一个同名文件夹里。

源码运行时，位置改为 `deskpet-plus/app/character-resources`，与 `main.js` 同级。自行从源码构建出的应用，则将资料文件夹放到 `DeskpetPlus.exe` 同级。

### 第三步：刷新、校验、选择角色

1. 启动程序；已经启动时点击工坊的 **“刷新角色库”**。
2. 点击 **“校验角色资料包”**。当前原资料包应检查 4,494 个文件；过程中显示进度，可以取消。
3. 校验通过后点击 **“角色设置”**，选择角色及服装。
4. 想显示两个人时，进入 **“双人设置”** 开启双人模式，再分别选择左右角色。
5. 想听配音时，在 **“系统设置”** 开启“播放日语配音”，并确认桌宠音量和系统音量。

资料已识别但只看到工坊时，从系统托盘菜单点击 **“显示桌宠”**。

这套资料包含 MyGO!!!!! 与 Ave Mujica 共 10 位角色、51 套服装，以及普通语音、配对对白、互动表情与演奏配置。原角色资料按整包加载，无需当作普通自定义模型逐个重新导入。

## 三、怎样触发双人互动

- 先开启双人模式，并选择两位具有配对资料的不同原角色。
- 两人加载完成后，支持的组合会触发一轮预设对白。
- 后续随机互动通常在用户约 15 秒无操作后触发；一轮结束后会有约 30～60 秒间隔。
- 想在继续操作其他窗口时观看互动，可以开启桌宠工具栏的锁定显示。锁定也会固定位置并保持显示。
- 同团支持的组合有专属配对对白。跨团组合目前先进行无配音的通用文字问候，之后按现有逻辑播放随机动作。
- 角色切换、动作预览、模型加载等状态可能暂时影响互动；可以先等待当前操作结束。

互动来自预设资料。其他自行导入的角色可以同屏，但不会自动获得这些原角色对白。

## 四、怎样使用音乐演奏和《春日影》反应

在能够提供 Windows 系统媒体会话信息的播放器中播放音乐或视频，程序检测到播放状态后，会按原角色配置切换演奏动作；停止播放后返回日常状态。也可在“角色设置”中手动预览演奏。

单人模式识别到媒体标题“春日影”或“Haruhikage”时，高松灯、长崎爽世、椎名立希、若叶睦和丰川祥子可以进入已适配的特殊反应。双人模式按普通音乐演奏处理。

该功能依赖播放器提供的状态和标题，不能保证识别所有网页，也不会通过麦克风识别歌曲或自动分析节拍。

## 五、导入自己的 Live2D

1. 准备包含 `.model3.json`、`.moc3`、贴图及所引用文件的完整目录或 ZIP。
2. 在工坊点击 **“导入模型文件夹”** 或 **“导入 ZIP”**。
3. 根据提示选择模型入口、填写名字并加入角色库。
4. 先检查预览和动作，调整缩放及位置。
5. 选择单人、双人左侧或双人右侧，再点击 **“放到桌面”**。

若模型入口引用上级的共享 `assets`，请提供包含共享资源的上级目录。只有 PSD、`.cmo3` 工程或单张图片，不能作为完整运行模型直接导入。

## 六、源码运行

准备 Windows、Node.js 22.12.0 或更高版本及可用的 npm。在仓库根目录打开 PowerShell：

```powershell
cd .\deskpet-plus\app
npm ci
npm start
```

首次安装需要联网下载 Electron 等依赖。源码模式使用 `app/data`，与便携程序的 `desktop-pet/data` 分开保存。

## 七、设置与备份

个人设置、导入角色和制作记录保存在程序的 `data` 中。更新程序前可以另存这个目录；更换运行目录后若想继续使用原设置和自定义角色，保留并带上相应的 `data`。

原内置资料保存在独立的 `character-resources`，不包含个人设置。资料校验只读取并比对文件，不会修改角色素材。

## 八、遇到问题

| 情况 | 先检查 |
|---|---|
| 启动后没有角色 | 是否已安装整包资料或导入模型，资料目录是否放对 |
| 校验失败 | 复制是否完整，文件名是否改变，先记下界面提示的缺失文件 |
| 没有声音 | 日语配音开关、桌宠音量、系统混音器，以及原始资料中的音频文件 |
| 双人不说话 | 双人模式、角色组合、加载状态、闲置条件和互动间隔 |
| 音乐没有触发表演 | 播放器是否提供系统媒体会话信息，可先手动预览演奏 |
| 图片试验没有内置图 | 选择自己的图片，或安装完整原资料后重新打开试验台 |

提交问题时附上程序版本、操作步骤、错误提示和截图。不要附带密码、Token 或个人设置中的敏感信息。

当前仍为 Beta。自动检查已覆盖模型与资料恢复、互动逻辑及异步校验；实际窗口、扬声器播放、外部 PSD2Live 生成及公开源码的完整独立构建仍需进一步实机验收。
